# 🌍 Countries Data Analysis

## 📌 Overview

This project is a data analysis project built using **Python and Pandas**. It analyzes a dataset containing information about countries around the world and extracts useful insights using data filtering, sorting, aggregation, and other Pandas operations.

## 📊 Dataset

The project uses `Countries.csv`, which contains country-level information such as population, capital, continent, region, democracy score, political leader, and other attributes.

## 🔎 Analysis

The notebook performs different analyses on the dataset, including:

* Finding the country with the highest population
* Finding the country with the lowest population
* Finding the capital of the least populated country
* Finding the top 5 countries by democracy score
* Finding the total number of regions
* Filtering countries from Eastern Europe
* Finding the political leader of the second most populated country
* Finding countries with unknown political leaders
* Finding countries with "Republic" in their name
* Finding the most populated country in Africa
